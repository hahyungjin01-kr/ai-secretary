# Traders AI

모드 기반 **일일 자동 분석 → 알림 → 금액 입력 → 모의 체결** 앱입니다.

## 제품 흐름

1. **모드 선택**: 안전형 / 밸런스형 / 수익형
2. **매일 자동 분석**: 관심종목의 시세·차트(RSI/볼린저)·거래량·뉴스를 앱이 조사
3. **알림**: “얼마를 투자할까요?” / “얼마를 매도할까요?”
4. **실행**: 사용자가 금액만 입력 → 모드 한도 안에서 수량·체결을 시스템이 결정

> MVP는 **모의투자(페이퍼 트레이딩)** 입니다. 실계좌 증권사 주문 연동은 아직 없습니다.

## 모드 차이

| 모드 | 1회 손실한도 | 종목 최대비중 | 현금 최소 | 매수 알림 |
|------|-------------|--------------|----------|----------|
| 안전형 | 0.75% | 12% | 25% | 최대 2건/일 |
| 밸런스형 | 1.5% | 22% | 15% | 최대 4건/일 |
| 수익형 | 3% | 35% | 5% | 최대 6건/일 |

## 실행

```bash
cd traders-ai
npm install
npm run dev
```

- Web: http://localhost:5173
- API: http://localhost:8787

상태 파일: `data/state.json`

## API

- `GET /api/dashboard` — 포트폴리오·알림·모드
- `PATCH /api/settings` — `{ mode, watchlist, cash }`
- `POST /api/daily/run` — `{ force?: boolean }` 일일 스캔
- `POST /api/alerts/:id/act` — `{ amount, action: "execute" | "skip" }`

## 면책

교육/모의투자 도구입니다. 투자 손실이 발생할 수 있으며, 수익을 보장하지 않습니다.
