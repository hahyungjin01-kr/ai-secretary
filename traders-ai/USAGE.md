# Traders AI 사용 가이드

이 앱은 **관심종목을 사용자가 고르지 않습니다.**  
모드만 고르면, AI가 매일 “어떤 종목에 / 어떻게 투자할지”를 스스로 제안합니다.  
사용자는 알림에 나온 **금액만 확인**하면 됩니다.

---

## 1. 이 앱이 하는 일 / 안 하는 일

### 하는 일
- 모드(안전형·밸런스형·수익형)에 맞게 **종목 선정**
- 시세·차트·거래량·뉴스·토스 랭킹을 **스스로 조사**
- 진입가·목표가·손절·투자 방식·추천 금액을 **정리**
- 토스증권 계좌 **잔고/보유 동기화**
- LIVE를 켠 경우 **토스 주문 실행**

### 안 하는 일
- 관심종목을 사용자가 일일이 입력하게 하지 않음
- LIVE를 켜기 전에는 **실주문하지 않음** (로컬 모의체결)
- 수익을 보장하지 않음

## 2. 처음 한 번만 하는 준비

### 2-1. 토스증권 Open API 연결
1. 토스증권 → **설정 → Open API**
2. `client_id`, `client_secret` 발급
3. **허용 IP**에 서버 공인 IP 등록  
   (연결 실패 시 앱/에이전트에게 현재 IP를 다시 받아 추가)
4. 파일에 키 저장:

**경로:** `/workspace/traders-ai/.env`

```env
TOSS_CLIENT_ID=발급받은값
TOSS_CLIENT_SECRET=발급받은값
# TOSSINVEST_ACCOUNT=1   # 선택 (비우면 자동 선택)
```

### 2-2. 모바일 고정 주소 (ngrok)
이미 설정된 경우 이 주소로 접속합니다.

**https://supermom-overspend-numeric.ngrok-free.dev**

`.env` 예시:

```env
NGROK_AUTHTOKEN=ngrok토큰
NGROK_DOMAIN=supermom-overspend-numeric.ngrok-free.dev
```

서버/터널 재시작:

```bash
cd /workspace/traders-ai
npm run start:mobile
```

## 3. 매일 쓰는 방법 (핵심)

### ① 앱 열기
- 모바일: https://supermom-overspend-numeric.ngrok-free.dev  
- PC: http://localhost:8787 (서버가 켜져 있을 때)

### ② 모드 선택
| 모드 | AI가 고르는 방식 | 성향 |
|------|------------------|------|
| 안전형 | 대형 유동성 + 급락 후 반등 | 보수 |
| 밸런스형 | 거래대금·완만한 모멘텀 | 중간 |
| 수익형 | 급등·거래량 모멘텀 | 공격 |

### ③ 「오늘 AI 선정 실행」 누르기
AI가:
1. 시장 랭킹에서 후보를 뽑고  
2. 차트/수급/뉴스를 보고  
3. 매수·매도 제안을 만듭니다  

### ④ 알림 확인
각 제안에는 다음이 포함됩니다.
- 왜 골랐는지
- **투자 방식** (어떻게 들어갈지)
- 현재가 / 목표 / 손절
- AI 추천 금액

### ⑤ 금액 확인 후 실행
- 추천 금액을 그대로 쓰거나 수정
- **매수/매도 실행** 또는 **오늘은 건너뛰기**

> LIVE가 꺼져 있으면 연습(모의)으로만 체결됩니다.  
> LIVE가 켜져 있으면 토스 실계좌로 주문이 나갑니다.

## 4. 계좌·실주문 안전장치

### 잔고 동기화
화면의 **잔고 동기화**를 누르면 토스 현금/보유가 앱에 반영됩니다.

### 실주문 켜기 (주의)
1. 계좌 연동 상태가 “연결됨”인지 확인
2. 입력칸에 `LIVE` 입력
3. **실주문 활성화**

끄려면 **실주문 잠그기**를 누릅니다.

### 모드별 한도 (자동 적용)
| 항목 | 안전형 | 밸런스형 | 수익형 |
|------|--------|----------|--------|
| 1회 손실한도 | 0.75% | 1.5% | 3% |
| 종목 최대비중 | 12% | 22% | 35% |
| 현금 최소 | 25% | 15% | 5% |
| 하루 매수 알림 | 최대 2건 | 최대 4건 | 최대 6건 |

## 5. 화면 구성 요약

1. **모드 카드** — 투자 성향 선택  
2. **총자산 / 현금 / 손익 / 대기 알림** — 현황  
3. **계좌 연동 (토스증권)** — 연결·동기화·LIVE  
4. **AI 일일 종목 선정** — 오늘 스캔 실행  
5. **AI 오늘의 투자 제안** — 매수/매도 카드  
6. **보유 포지션 / 최근 체결** — 결과 확인

## 6. 자주 묻는 질문

### Q. 관심종목은 어디에 넣나요?
넣지 않습니다. AI가 매일 모드에 맞게 고릅니다.

### Q. 모바일에서 안 열려요.
1. 서버/터널이 켜져 있는지 확인 (`npm run start:mobile`)  
2. ngrok 첫 화면이 뜨면 계속하기  
3. 주소가 맞는지 확인: `https://supermom-overspend-numeric.ngrok-free.dev`

### Q. 토스 연결이 “IP not allowed”예요.
허용 IP에 서버 공인 IP가 없습니다. IP를 다시 확인해서 토스 Open API 허용 목록에 추가하세요.  
이 서버는 IP가 여러 개일 수 있어, 안내받은 IP를 **전부** 넣는 것이 안전합니다.

### Q. 주문이 진짜로 나가나요?
- LIVE **꺼짐**: 모의체결만  
- LIVE **켜짐**: 토스 실주문  

### Q. 수익이 나나요?
아닙니다. 교육/의사결정 보조 도구이며 수익을 보장하지 않습니다.  
손실 위험이 있습니다.
