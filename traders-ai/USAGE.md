# Traders AI — 쓰는 법

계좌 돈으로 AI가 고르고, **사전거래 MoA 통과 + 「허락」 입력**일 때만 주문합니다.

## 분석·주문 파이프라인
1. **MoE** — 기술/모멘텀/밸류/리스크/뉴스 (독립 렌즈)
2. **MoA** — 제안 에이전트 3인 과반 + 집계
3. **악마의 변호인** — 문제 제기 시 **중단하지 않고** 분석 MoA 재실행 → 축소 허용안 탐색
4. 사용자 「허락」 입력
5. **사전거래 MoA** — soft-deny면 다시 분석 MoA로 허용안 수정 / 장외만 하드 차단
6. 건별 일회성 주문 (LIVE 영구 무장 없음)

## 접속
- 모바일: https://supermom-overspend-numeric.ngrok-free.dev
- PC: http://localhost:8787

`.env`에 `TRADERS_AI_TOKEN`이 있으면 앱에 같은 토큰을 저장하세요.

## 쓰는 순서
1. 잔고 새로고침
2. AI에게 맡기기
3. 빼기만 하고 **최종 확인** 버튼 한 번

종목마다 글을 입력하지 않습니다.

수익 보장 없음. 실주문 손익은 사용자 책임입니다.
