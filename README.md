# ai-secretary

## Traders AI

모드형 일일 트레이딩 앱은 [`traders-ai/`](./traders-ai/)에 있습니다.

```bash
cd traders-ai && npm install && npm run dev
```

- 모드: 안전형 / 밸런스형 / 수익형
- AI가 매일 종목·투자방식을 스스로 선정 후 알림
- 사용자는 금액만 확인 → **토스증권**으로 주문
- 키 없거나 LIVE 잠금이면 로컬 모의체결
- 사용 가이드: [`traders-ai/USAGE.md`](./traders-ai/USAGE.md)
